# FitLog

FitLog 是一个个人健身记录与训练分析项目，支持手动记录训练，也能从本地 Markdown 日记中提取训练数据。

## 主要功能

- 记录训练日期、动作、组数、重量和次数，支持修改、删除记录和标记休息日。
- 浏览、搜索和筛选训练记录与 Markdown 日记。
- 使用 AI 提取日记中的训练数据，经人工核对和修正后保存确认结果。
- 查看训练活动、动作历史及重量或次数变化，通过动作别名统一同一动作的不同名称。

## 数据来源与边界

- 手动录入的训练记录保存在本地数据库，不依赖 Markdown 资料库或 AI。
- 本地 Markdown 资料库是只读来源，日记内容可参考 [训练日记示例](docs/DiaryExample.md)。应用不改写原文件，也不进行双向同步。
- Markdown 原文、AI 候选和人工确认值分开保存，重新解析不会覆盖人工修正。
- 统计使用手动记录，以及当前资料库中已确认且与最近核验的原文版本一致的记录。
