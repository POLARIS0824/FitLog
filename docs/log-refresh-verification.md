# Log 增量核对与真机验收

实现使用应用级 SourceIndexRepository 调度；Log 仅观察 Room 索引。普通页面导航和 Editor 返回不扫描，Editor 保存（包括恢复后写入）直接更新单条索引。扫描不会因 Log ViewModel 清理而取消；切换或解除资料库会取消旧操作。

## 调度与准确性

- 冷启动首次连接当前资料库时后台核对；无已完成全文校验时读取全文，空库也记录完成状态。
- 实际从后台回前台：距离上次核对尝试至少 30 秒。观察器注册和 Activity 重建的生命周期补发不会触发刷新。
- Log 前台持续可见：每 5 分钟核对。页面进出不立即触发核对。
- 自动核对枚举子目录，只读取新增、元数据变化、元数据未知、未验证或之前读取失败的文件。
- 最近成功全文校验超过 24 小时，下次自动核对升级为全文校验；手动刷新和显式 Import 强制全文核对。
- 自动间隔使用单调时钟，持久化的成功时间使用 UTC 时间戳。时间回拨导致全文时间在未来时，执行全文校验。
- 完整枚举才能标记缺失。目录加载中、部分失败、权限失败和中断不会把未发现来源标记为缺失。
- 元数据相同不保证正文相同。保留时间和大小的外部修改通过全文校验兜底；打开原文和写回冲突检查始终访问实际文件。
- 索引写入失败保留独立于 Room 的修复标记，下一次核对强制验证。原文保存成功不依赖索引成功。
- 数据库 v1 → v2 只增加可空字段，保留原记录；旧记录重新验证元数据。

## 待完成的真机验收

使用实际 SAF 本地目录和日常使用的 Obsidian／同步工具分别验证；自动测试不能证明提供方的时间戳和权限行为。

1. 导入含子目录的资料库，再导入空目录和只读目录；确认进入 Log，扫描结果和连接成功分别反馈。
2. 在 Log 搜索、排序并滚动后切换底部页面、旋转屏幕；确认列表状态保留，普通返回没有扫描进度。
3. 保存现有日记、新建日记、恢复草稿后保存；返回 Log，确认文件立即更新且不全量扫描。
4. 离开应用，在外部编辑、创建、移动、重命名和删除 Markdown；距离上次核对超过 30 秒后返回，确认列表后台更新。30 秒内返回允许先显示缓存，可手动刷新。
5. 保持 Log 可见超过 5 分钟，外部修改应在下一次核对被发现。检查正文修改和文件新增／删除。
6. 手动刷新，确认立即全文校验。测试同大小且保留时间戳的修改时，应能检测；自动全文兜底的 24 小时边界由注入时钟测试验证。
7. 在大资料库扫描途中切换页面，扫描应继续；切换／解除资料库时，旧结果不能替换当前列表。
8. 撤销系统授权、使目录不可用或模拟子目录读取失败；确认错误明确、缓存可保留，未发现记录不被误判为缺失。重新授权后刷新可恢复。
9. 从使用 v1 索引的旧安装覆盖升级，确认原索引、资料库配置、草稿及 Markdown 均保留。
