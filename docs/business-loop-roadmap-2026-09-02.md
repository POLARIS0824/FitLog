# 业务闭环路线图（2026-09-02 · PM 视角）

## 产品定位

单用户 AI 健身记录 App（自用 + 作品集/演示）：用户以**计划**为纲完成每周训练，
训练过程在 App 内执行与记录，数据沉淀为统计与趋势，AI 教练基于真实数据给出
观察建议并代行部分操作。

## 核心业务环与断点诊断

```
①计划 → ②训练执行 → ③记录沉淀 → ④回顾分析 → ⑤洞察反馈 → ⑥调整计划 ─┐
   ↑______________________________________________________________|
```

| 环节 | 现状 | 断点 |
|---|---|---|
| ①计划 | 预置计划可查看/激活，Today 卡推进下一课次 | **计划不可删除**（删光预置后不重灌的仓库能力已备好但无 UI）；**计划不可创建**——用户不能自建，AI 教练 12 个工具里也没有"落库计划"的写路径（能说不能做） |
| ②执行 | 会话流完整：计划预填/进程死亡恢复/占位组/清洗落库/课次回写 | **无组间休息计时**（力量训练刚需）；**动作示范图缺失**——assets 里 12MB/1322 张动作图零消费，遇到不认识的动作无处可看 |
| ③沉淀 | 手动会话 + Markdown 导入双通道 | **无导出**。导入出去的数据回不来：数据所有权不闭环，作品集演示也缺少"数据可迁移"的叙事 |
| ④回顾 | Stats 四档图表/53 周热力图/体重折线；历史可展开、可删除 | 已闭环（动作维度趋势属增强，非断点） |
| ⑤洞察 | Coach Insight 规则+AI 双版；Agent 深度读数据（12 工具） | "AI 分析"占位卡无出口：Today 里看见分析入口却进不去 |
| ⑥调整 | AI 可切激活计划（SetActivePlanTool）、可记体重 | 即环节①的断点：调整 = 换计划（可）+ 建计划（不可）+ 删计划（不可） |

结论：**闭环缺口集中在①/⑥（计划管理）与③（导出）**，②/⑤各有一个低成本补全点。

## 已实施（feat 分支，每功能一提交）

| 编号 | 功能 | 闭环意义 | 实现要点 |
|---|---|---|---|
| F-01 | 训练数据 Markdown 导出 | ③ 沉淀闭环：导入⇄导出对称，数据所有权完整 | 与导入格式对称的 Markdown 序列化（含结构化明细），SAF CreateDocument 写出，导出报告 Snackbar 反馈 |
| F-02 | 计划管理：删除计划 | ①/⑥ 管理闭环：PlanPickerSheet 支持删除并确认；删光预置后不再复活（仓库已备好的 `PRESET_PLANS_CLEARED` 能力首次接线） | |
| F-03 | AI 教练创建计划（CreatePlanTool） | ⑥ 调整闭环：AI 的建议可以落地为系统计划，写路径 2→3 | 结构化参数 + 确认门（复用 request_confirmation 流），校验 exerciseKey 存在性，落库后可选直接激活 |
| F-04 | 动作示范图 | ② 执行质量：会话内动作卡可见示范图，激活 12MB 沉睡资产 | BitmapFactory 异步解码 assets，缺图/非图片资源优雅降级（回归此前删除的 2 张图场景） |
| F-05 | 组间休息计时器 | ② 执行质量：力量训练组间休息有据可依 | 录组后自动开始 90s 倒计时，可暂停/跳过/+30s，纯会话页 UI 层，不落库 |
| F-06 | 聊天语音输入（实装麦克风） | ⑤ 洞察入口可用性：审查遗留的"死按钮"清账 | SpeechRecognizer 原生能力接线；Live/附加按钮在能力就绪前隐藏 |
| F-07 | "AI 分析"占位卡接线 | ⑤ 洞察闭环：占位卡 → 带预填分析请求跳转 AI 教练 | ChatKey 携带预填参数（@Serializable 默认值保证旧回退栈兼容） |

## 明确不做（本阶段）

- **补剂摄入/运动目标占位卡**：需要新表（DB v10）与独立管理 UI，价值密度低于上述七项；占位卡保留。
- **动作维度历史趋势（Stats）**：增强项非断点；PR 口径已在 Today VOLUME_PR 模式存在。
- **训练记录编辑**：低频需求，删除重建可覆盖。
- **自定义动作创建**：动作库 1324 条 + AI 检索已覆盖绝大多数场景。

## 度量口径提醒

新增能力一律复用 `util/VolumeAggregator` / `VolumeFormatter` / `Workout.isCountable`
口径（本次审查已收口），禁止行内手写聚合。
