## 实机检查清单（约 15–20 分钟）

1. **今日日记入口**：打开 FAB，确认只有 Open Today Log 和 Import Folder。未连接时进入连接流程，取消不创建文件；连接后继续今日日记。空白退出不创建文件，输入保存后再次打开直接进入同一篇，无同名确认。
2. **日记设置**：从 Log 打开日记设置，选择已有子目录，分别试三种日期格式。检查文件名预览及实际创建目录。设置变更不移动旧文件；切换资料库再切回，日记设置仍独立保留。
3. **原文编辑**：中文组字、多行粘贴、长文滚动、打开键盘后操作格式工具。输入无序／有序／任务列表后回车，检查续写和空项退出；缩进后撤销、重做，检查选区和原文。只读日记可查看，不可编辑。
4. **Log 列表**：检查单条、多条及搜索过滤后的首尾圆角；搜索文件名和子目录路径；切换正序／倒序后重启确认排序保留。编辑返回后内容列表刷新，搜索条件保留。检查深色模式、大字体和读屏名称。
5. **恢复路径**：撤销 SAF 权限后尝试打开、刷新和保存；确认有反馈且输入保留。外部修改同一文件后保存应提示冲突；另存副本应在原文件所在目录。删除设置中的日记目录后，应提示处理而非静默回退到根目录。

## 本轮约定

- 今日日记按点击时的设备本地日期定位；已打开的编辑会话跨午夜不自动改名。
- 日记目录默认资料库根目录，只能选择已有子目录；默认日期格式 `YYYY-MM-DD.md`。
- Log 展示整个资料库的 Markdown。排序是文件名文本排序，不将非日期命名的笔记推断为训练日期。
- 搜索只匹配文件名与相对路径，不扫描正文；默认文件名倒序。
- 本文对应今日日记最初交付，不包含 Markdown 预览、附件管理或 AI 解析。后续恢复中心、资料库管理与持久来源索引见 [原文恢复与索引](recovery-vault-index.md)，其验证范围按新文档执行。
